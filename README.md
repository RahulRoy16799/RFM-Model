# RFM-Model
This project focuses on Customer Segmentation using RFM Analysis (Recency, Frequency, Monetary Value) on the Online Retail dataset. The goal is to analyze customer purchasing behavior and segment customers into meaningful groups to support targeted marketing strategies.

The workflow includes data cleaning, preprocessing, and exploratory data analysis to understand customer patterns. RFM metrics are calculated for each customer, capturing how recently they purchased (Recency), how often they purchase (Frequency), and how much they spend (Monetary Value).

Customers are then segmented based on their RFM scores, allowing identification of key groups such as high-value customers, loyal customers, and at-risk customers. The results are visualized using various plots to provide clear business insights.

This project demonstrates how data-driven techniques can be used to improve customer retention, personalize marketing efforts, and increase revenue.

Dataset Link: https://www.kaggle.com/datasets/ulrikthygepedersen/online-retail-dataset
